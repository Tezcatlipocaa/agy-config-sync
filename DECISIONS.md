# Architecture Decision Records (ADR) / Registro de Decisiones

This document records architectural decisions made for your Antigravity CLI setup.
The AI Agent curator **must respect these records** and not re-propose changing them unless explicitly requested.

Este documento registra las decisiones acordadas para la configuración de Antigravity CLI.
El Agente curador **debe respetar estos registros** y no volver a proponer modificarlos salvo indicación explícita.

---

### Format Example / Formato de Ejemplo:

```markdown
### ADR-001: [Title / Título]
- **Status / Estado**: Accepted | Supervised | Deprecated
- **Context / Contexto**: Why this decision was needed / Por qué se tomó.
- **Decision / Decisión**: What is configured / Qué se acordó.
- **Consequences / Consecuencias**: Impact on sync or agent behavior / Impacto.
```
